# Contributing to Muslim Zone

Thank you for your interest in contributing to **Muslim Zone**! ❤️

Contributions of all kinds are welcome, including bug fixes, features, UI improvements, translations, Islamic content, documentation, and more.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install dependencies:

```bash
pnpm install
```

4. Create a new branch:

```bash
git checkout -b <branch-name>
```

5. Make your changes.
6. Test your changes.
7. Commit and push your branch.
8. Open a Pull Request.

## Commits Convention

- `feat`: all changes that introduce completely new code or new
  features
- `fix`: changes that fix a bug
- `refactor`: any code related change that is not a fix nor a feature
- `docs`: changing existing or creating new documentation (i.e. README, docs for
  usage of a lib or cli usage)
- `build`: all changes regarding the build of the software, changes to
  dependencies or the addition of new dependencies
- `test`: all changes regarding tests (adding new tests or changing existing
  ones)
- `ci`: all changes regarding the configuration of continuous integration (i.e.
  github actions, ci system)
- `chore`: all changes to the repository that do not fit into any of the above
  categories

## Before Submitting

Please run:

```bash
pnpm typecheck
pnpm lint
```

Also test the application affected by your changes.

## Pull Requests

Before opening a Pull Request:

- Make sure your changes are focused.
- Check your code for unnecessary changes.
- Make sure the relevant checks pass.
- Clearly describe what you changed.

## Islamic Content

If you contribute Islamic content such as Duas, translations, Quran references, or Hadith references, please make sure the information is accurate and include a reliable source when applicable.

## Bug Reports

Please search existing issues before reporting a new bug.

Include:

- What happened
- What you expected
- Steps to reproduce
- Platform/device
- Screenshots or logs when helpful
